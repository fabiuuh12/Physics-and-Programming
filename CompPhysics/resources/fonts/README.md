# Interface font

`Inter-Regular.ttf` is a static Latin/Greek subset of Inter, instantiated at
weight 400 and optical size 18 from the Google Fonts variable font.

Upstream: https://github.com/google/fonts/tree/main/ofl/inter

Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).
Distributed under the SIL Open Font License 1.1; see `OFL-Inter.txt`.
The subset retains the font's naming and license metadata. It was generated
with fontTools; fontTools is not needed to build or run the simulations.

The simulations resolve this asset relative to the executable or project
directory, and fall back to raylib's default font if it is absent.
