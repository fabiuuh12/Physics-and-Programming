# Physics simulations

Choose a subject below. Each folder contains standalone demos and, where needed, supporting Python code or technical notes. Technical reference documents live under `CompPhysics/docs/reference/`. Shared graphics and numerical helpers live in [`../common/`](../common); camera bridges live in [`../vision/`](../vision).

From the repository root:

```bash
python3 explore.py list mechanics
python3 explore.py info projectile_drag_viz
python3 explore.py run projectile_drag_viz
```

See the [full file catalog](../../docs/CATALOG.md) for individual sources, and [getting started](../../docs/GETTING_STARTED.md) for dependencies. The launcher builds a selected C++ demo before opening it. Each demo displays its own controls.
