# Project code

| Folder | Contents |
| --- | --- |
| [simulations](simulations/README.md) | Physics and mathematics demonstrations grouped by subject |
| [cybertools](cybertools/README.md) | Security, network, forensics and file utilities |
| [vision](vision/) | Camera experiments and hand-input bridges |
| [optics](optics/) | Shared Python scenes used by the camera runners |
| [common](common/) | Shared C++ rendering, numerical and path helpers |

Use `python3 explore.py` from the repository root to browse and run standalone programs. The [catalog](../docs/CATALOG.md) also includes supporting modules, which are imported by programs rather than run independently. Keep generated files in [`../output/`](../output/README.md).
